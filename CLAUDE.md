# Проект: торговый бот Solana / pump.fun (Node >=22, ESM)
Цель: стратегия с положительным матожиданием ПОСЛЕ издержек. Сначала dry-run/shadow.
Язык ответов: русский, коротко. Код и команды как есть.

## Запреты (для всех)
- Не читать и не печатать .env, keys/, data/, ключи, seed, RPC-ключи.
- Не запускать --live, не ставить LIVE_CONFIRM=yes / LIVE_CONFIRM_AMM=yes, не слать транзакции.
- Commit/push только через `npm run ship -- "сообщение"` и только по моей команде.
- TP/SL/ставку/лимиты не менять без моего решения.

## Роли
- КОДИНГ: правит критичный код (деньги, комиссии, PnL, live-гейты, AMM-продажа). К каждой правке тест.
- ПРОМТ: не правит код, пишет промты, ревьюит, анализирует журналы. Пишет только в agents/.
- Cline (DeepSeek): механические правки по agents/TASK.md, отчёт в agents/REPORT.md.

## Статистика
Уникальные mint = независимые наблюдения. Bootstrap только при n>=30, вывод о прибыльности при n>=200. Разные costsScheme не смешивать.
